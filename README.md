# 🇯🇵 Japan Electricity Consumption Prediction

[![Website](https://img.shields.io/website?url=https%3A%2F%2Fwww.japanconsumption.filipusarif.my.id%2F&label=visit&style=flat-square&logo=google-chrome&logoColor=white)](https://www.japanconsumption.filipusarif.my.id/)
[![Vercel Deploy](https://img.shields.io/badge/deployed%20on-Vercel-black?logo=vercel&style=flat-square)](https://vercel.com)
[![License](https://img.shields.io/badge/license-MIT-blue.svg?style=flat-square)](LICENSE)

A web-based application for **forecasting electricity consumption in Japan** using machine learning.  
This project provides interactive visualization and prediction results, aiming to support research, planning, and energy policy analysis.  

🔗 **Live Demo:** [https://www.japanconsumption.filipusarif.my.id/](https://www.japanconsumption.filipusarif.my.id/)

---

## ✨ Features
- 📊 Interactive charts for electricity consumption trends  
- ⚡ Machine learning–based prediction model  
- 🌐 Deployed with [Vercel](https://vercel.com) for fast global delivery  
- 📱 Responsive design for desktop and mobile  
- 🎨 Smooth animations with GSAP and React  

---

## 🛠️ Tech Stack
- **Frontend:** [React](https://react.dev) + [Vite](https://vitejs.dev) + [TailwindCSS](https://tailwindcss.com)  
- **Animations:** [GSAP](https://greensock.com/gsap/)  
- **Backend API:** [FastAPI](https://fastapi.tiangolo.com/) (Python)  
- **Deployment:** [Vercel](https://vercel.com) (frontend) + [Railway](https://railway.app) (backend)

## 🚀 Getting Started (Development)

### 1. Clone Repository
```bash
git clone https://github.com/yourusername/japan-electricity-consumption.git
cd japan-electricity-consumption
```

### 2. Install Dependencies
```bash
yarn install
# or
npm install
```

### 3. Setup Environment Variables
Create a `.env` file in the root directory:

```env
VITE_API_URL=https://your-fastapi-backend-url
```

### 4. Run Development Server
```bash
yarn dev
# or
npm run dev
```

The app will be available at `http://localhost:5173`

## 📦 Deployment
This project is deployed on **Vercel**.  
To deploy your own instance:
1. Fork this repository.  
2. Push your code to GitHub.  
3. Import the project into [Vercel](https://vercel.com/import).  
4. Configure environment variables in the Vercel dashboard.
